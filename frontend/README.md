# Robecruit frontend

The Robecruit dashboard is a React and TypeScript application built with Vite
and Tailwind CSS. Its dashboard values are example data; the other navigation
sections and backend integration are not implemented yet.

From this directory, install dependencies and start the development server:

```fish
npm install
npm run dev
```

By default, Vite serves the application at http://localhost:5173.

Run `npm run build` to type-check and create a production build in `dist/`.
Run `npm run lint` to check the source with Oxlint.
